# TW-MiniApp-Prototype 目录说明

这是一个轻量微信小程序原型目录，重点是页面结构和视觉验证，不是主工作区。

## 主要目录

- `pages`：原型页面。
- `assets`：图标、图片和 tabbar 资源。

## 主要配置

- `app.js`、`app.json`、`app.wxss`：小程序全局入口与配置。
- `project.config.json`、`project.private.config.json`：微信开发者工具配置。

## 使用建议

- 需要快速改页面、试布局、看交互时，优先在这里动。
- 需要处理完整文档、脚本、云函数或工具链时，去 `TW-MiniApp-Workspace`。
